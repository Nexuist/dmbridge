Suppose a friend sent a meme to your personal X account.

## Find the conversation

Open the latest conversation:

```sh
dmbridge x conversations list --account personal --limit 1 --pretty
```

        "latestMessageAt": "2026-10-14T19:42:11.000Z",
        "latestMessageID": "x-message-456",
        "muted": false,

dmbridge x conversations get x-conversation-123 \

## Heart the meme

Preview the mutation:

```sh
dmbridge x reactions add x-message-456 \
  --account personal --reaction '❤️' --dry-run --pretty
```

```json
{
  "account": "personal",
  "command": "x reactions add x-message-456",
  "ok": true,
  "protocolVersion": 1,
  "provider": "x",
  "requestID": "demo-request-4",
  "result": {
    "account": "personal",
    "dryRun": true,
    "operation": "add",
    "provider": "x",
    "request": { "reaction": "❤️" },
    "target": "x-message-456"
  }
}
```

Then run the same action without `--dry-run`:

```sh
dmbridge x reactions add x-message-456 \
  --account personal --reaction '❤️' --pretty
```

```json
{
  "account": "personal",
  "command": "x reactions add x-message-456",
  "ok": true,
  "protocolVersion": 1,
  "provider": "x",
  "requestID": "demo-request-5",
  "result": {
    "confirmed": true,
    "effect": "exact"
  }
}
```

## Reply

Text replies do not need a JSON request body. Preview this one first:

```sh
dmbridge x messages reply x-message-456 "sick meme" \
  --account personal --dry-run --pretty
```

```json
{
  "account": "personal",
  "command": "x messages reply x-message-456",
  "ok": true,
  "protocolVersion": 1,
  "provider": "x",
  "requestID": "demo-request-6",
  "result": {
    "account": "personal",
    "dryRun": true,
    "operation": "reply",
    "provider": "x",
    "request": { "text": "sick meme", "type": "text" },
    "target": "x-message-456"
  }
}
```

After inspecting the dry run:

```sh
dmbridge x messages reply x-message-456 "sick meme" \
  --account personal --pretty
```

```json
{
  "account": "personal",
  "command": "x messages reply x-message-456",
  "ok": true,
  "protocolVersion": 1,
  "provider": "x",
  "requestID": "demo-request-7",
  "result": {
    "confirmed": true,
    "effect": "exact"
  }
}
```

## Download the image

```sh
dmbridge x attachments download x-attachment-789 \
  --account personal \
  --destination-url "file://$HOME/Downloads/meme.jpg" --pretty
```

```json
{
  "account": "personal",
  "command": "x attachments download x-attachment-789",
  "ok": true,
  "protocolVersion": 1,
  "provider": "x",
  "requestID": "demo-request-8",
  "result": {
    "bytes": 184320,
    "destinationURL": "file:///Users/you/Downloads/meme.jpg",
    "mediaType": "image/jpeg",
    "sha256": "d8e8fca2dc0f896fd7cb4cb0031ba2493a8bdf6d2230c53a8f18b3f4c2e3d7a1"
  }
}
```

The result includes the destination URL, media type, byte count, and SHA-256
digest of the saved file.
