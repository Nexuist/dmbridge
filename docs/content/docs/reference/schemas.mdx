The complete public JSON Schema contract is rendered below. Schema version 5 is
immutable; an incompatible contract change will publish a new version.

Use the CLI to retrieve an individual schema as JSON:

```sh
dmbridge x doctor --schema message.send --pretty
```

## Source of truth

The runtime schemas are defined in
[`src/protocol.ts`](https://github.com/Nexuist/dmbridge/blob/main/src/protocol.ts).
Provider credential shapes live in
[`src/providers/x/credentials.ts`](https://github.com/Nexuist/dmbridge/blob/main/src/providers/x/credentials.ts)
and
[`src/providers/instagram/credentials.ts`](https://github.com/Nexuist/dmbridge/blob/main/src/providers/instagram/credentials.ts).
